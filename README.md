# PULSE — дашборд аналитики продукта

Адаптивная админ-панель на React + Vite. Графики и диаграммы нарисованы на SVG вручную — без Chart.js, Recharts и прочих тяжёлых зависимостей.

## Запуск

```bash
npm install
npm run dev
```

`npm run build` — production-сборка в `dist/`.

## Что внутри

- Четыре KPI-карточки со спарклайнами и динамикой.
- Линейный график: переключение метрики (выручка / заказы / пользователи) и периода (7 / 30 / 90 дней), тултип по наведению.
- Кольцевая диаграмма источников трафика с интерактивной легендой.
- Таблица заказов: поиск, фильтр по статусу, сортировка по колонкам, пагинация.
- Список задач с отметкой выполнения и прогресс цели.
- Выезжающий сайдбар на мобильных экранах.

Стек: React 18, Vite, чистый CSS. Все данные демо-генерируются в `src/App.jsx`.
